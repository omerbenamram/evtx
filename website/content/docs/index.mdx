Two command-line tools, `evtx_dump` and `mft_dump`, and the same parsers as Python packages and Rust crates. They read files you have already collected, with KAPE, Velociraptor, FTK Imager, The Sleuth Kit or anything else. They run on Linux, macOS and Windows, and none of them needs Windows to read a Windows artifact.

## What did you collect?

| You have | Run | Then read |
| --- | --- | --- |
| A Windows event log (`.evtx`) | `evtx_dump -o jsonl Security.evtx` | [evtx_dump](/docs/cli/evtx-dump) |
| An `$MFT` | `mft_dump -o csv '$MFT'` | [mft_dump](/docs/cli/mft-dump) |
| `$UsnJrnl:$J`, `$I30`, `$LogFile`, `$Boot` or `$Secure:$SDS` | `mft_dump -o jsonl '$J'` | [NTFS files](/docs/cli/ntfs-files) |
| A disk image, unallocated space or a memory dump, and you want the event logs in it | `evtx_dump --carve -o jsonl disk.raw` | [Deleted and damaged logs](/docs/guides/deleted-events) |

The single quotes matter in a Unix shell: without them `$MFT` is an empty variable.

## Working a case, or building a pipeline?

If you are at a terminal with a case open, use the command-line tools. They write JSON, CSV or XML that you can `grep`, feed to `jq`, or open in Timeline Explorer. Start at [evtx_dump](/docs/cli/evtx-dump) or [mft_dump](/docs/cli/mft-dump).

If the parser is a step in something that runs unattended, such as a SIEM ingest job or a collection pipeline, use the [Python packages](/docs/python/evtx) or the [Rust crates](/docs/rust/evtx), and read [Feeding a SIEM or pipeline](/docs/guides/siem-pipelines) before you choose settings.

## About the examples

Every command on this site was run, and its output is pasted as it came out. Where a line is too long to show, a `jq` filter in the command cuts it down, so you get the same thing when you run it.

The event log examples use sample logs from the [evtx repository](https://github.com/omerbenamram/evtx/tree/master/samples). The NTFS examples use the Narcos-1 teaching image from [Digital Corpora](https://digitalcorpora.org/): a Windows 10 laptop whose user ran CCleaner before it was seized, which makes it a good test of what survives a cleanup.
