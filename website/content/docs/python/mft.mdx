```bash
pip install mft
```

The package is the Rust parser behind `mft_dump`. Each record of the `$MFT` is an entry, with its full path already resolved:

```python
from mft import PyMftParser

parser = PyMftParser("$MFT")
for entry in parser.entries():
    if entry.full_path and "Documents\\Misc\\" in entry.full_path:
        print(entry.entry_id, entry.is_allocated, entry.file_size, entry.full_path)
```

```text
21220 True 1126370 Users\Steve Kowhai\Documents\Misc\BNE.png
86055 True 149936 Users\Steve Kowhai\Documents\Misc\Method Route.jpg
86111 True 142877 Users\Steve Kowhai\Documents\Misc\Airport Crystals.jpg

122442 True 110802 Users\Steve Kowhai\Documents\Misc\DropOff.jpg

```

That loop goes through all 127,480 records of this `$MFT` in 0.4 seconds. `is_allocated` is `False` for a deleted file, and paths use backslashes, as Windows wrote them.

## Common jobs

**Both sets of timestamps of a file**

```python
from mft import PyMftParser, PyMftAttributeX10, PyMftAttributeX30

entry = PyMftParser("$MFT").get_entry(95496)
print(entry.full_path)
for attribute in entry.attributes():
    content = attribute.attribute_content
    if isinstance(content, PyMftAttributeX10):    # $STANDARD_INFORMATION
        print("SI created", content.created)
    elif isinstance(content, PyMftAttributeX30):  # $FILE_NAME
        print("FN created", content.created, content.name)
```

```text
Users\Steve Kowhai\Desktop\OpenOffice 4.1.6 (en-US) Installation Files\openoffice1.cab
SI created 2018-10-24 02:35:22+00:00
FN created 2019-01-28 21:03:34.392223+00:00 OPENOF~1.CAB
FN created 2019-01-28 21:03:34.392223+00:00 openoffice1.cab
```

The attribute classes are named after the attribute type numbers: `X10` is `$STANDARD_INFORMATION` and `X30` is `$FILE_NAME`. A file has one `$FILE_NAME` for each name, and here one of them is the short 8.3 name. Timestamps are `datetime` objects in UTC. A `datetime` holds microseconds, so the seventh decimal place that the CSV and JSON output have is dropped.

This file's creation time in `$STANDARD_INFORMATION` is three months before the one in `$FILE_NAME`. Here it is an installer that restored the original dates. See [the note on timestomping](/docs/cli/mft-dump#questions-to-ask-it) before you read more into a gap like this.

**The same output as `mft_dump`**

```python
parser = PyMftParser("$MFT")

with open("mft.csv", "wb") as out:
    out.writelines(parser.entries_csv())    # the rows of mft_dump -o csv

for line in parser.entries_json():          # one JSON string per record, as mft_dump -o jsonl
    ...
```

Use these when you want every record: the rows are built in Rust, not in your loop.

**Don't let a damaged record end the job**

```python
parser = PyMftParser("$MFT", skip_errors=True)
```

Real `$MFT`s have damaged records. By default the first one raises `RuntimeError` in the middle of your loop. With `skip_errors=True` each becomes a `RuntimeWarning` such as `Skipping entry 32842: RuntimeError: Bad signature: [1, 0, 0, 0]`, and the loop goes on.

**Read from a file object**

`PyMftParser` takes a path, or a binary file object with `read` and `seek`, such as an `$MFT` inside a zip or one streamed from an image.

## Timelines and file contents

<Callout title="Not in a release yet" type="warn">
`entries_bodyfile()` and `data_streams()` are in the repository and ship with the next release of the `mft` package.
</Callout>

```python
from mft import PyMftParser

parser = PyMftParser("$MFT")

with open("mft.body", "w", encoding="utf-8", newline="") as body:
    body.writelines(parser.entries_bodyfile())   # for mactime

for stream in parser.data_streams(86111):
    print(repr(stream.name), stream.size, stream.data)
```

```text
'' 142877 None
'Zone.Identifier' 92 b'[ZoneTransfer]\r\nLastWriterPackageFamilyName=Microsoft.ScreenSketch_8wekyb3d8bbwe\r\nZoneId=3\r\n'
```

`data_streams` gives the `$DATA` streams of a record. The unnamed one is the file's content, and the named ones are alternate data streams. `data` holds the bytes when they are stored inside the MFT record, which is the case for small streams such as `Zone.Identifier`, and `None` when they are out on the disk. See [Building a timeline](/docs/guides/timelines) for what to do with the bodyfile.
